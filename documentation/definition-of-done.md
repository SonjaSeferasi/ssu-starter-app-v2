# SocialU Definition of Done

Prepared for CSC 351 Sprint 1. Linh Nguyen confirmed on October 15, 2026 that the team agreed to this Definition of Done. This records that confirmation; it does not backdate team adoption.

An SRS item may be marked Done when all of these are true:

- Its issue uses the exact SRS identifier, owner initials, and title, and includes the requirement’s shall statement and Traces to line.
- Its task sub-issues cover the database/data contract, API, UI, and verification needed for that specific behavior. Existing schema may satisfy the database layer without a new migration.
- The behavior works end to end in the running integrated application and meets the SRS acceptance criterion.
- Relevant automated checks pass; live acceptance evidence is recorded separately from mocked API tests.
- A pull request from the SRS-named branch is merged, references the SRS issue, and uses Closes #<task> for the tasks it actually completes.
- The SRS issue links its branch and merged PR and includes a screenshot of the real running behavior.
- No credentials, private student information, or OTPs are committed or included in evidence.
- Remaining gaps are stated honestly; incomplete work stays open and returns to Product Backlog for the next sprint as appropriate.

Update board status when work changes. Do not backdate history or imply that a later correction was recorded earlier in the sprint. Do not edit or move another person's cards without permission.
