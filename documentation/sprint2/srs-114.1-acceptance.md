# SRS-114.1 — Add Friend action — Linh Nguyen

Acceptance audit recorded October 22, 2026; parent issue #502.

The system shall provide an Add Friend action on another student's profile when the viewing student is eligible to send a friend request.

Acceptance criterion: Given two students are not friends, no request is pending, and no block exists, when one student opens the other's profile, then Add Friend is displayed.

Traces to: UR-114

## Existing vertical slice

1. `socialu_relationship` / `socialu_friendships` resolve current friendship, pending request and block state from existing tables.
2. `GET /api/friends?view=relation&username=...` derives the viewer from `verifiedUser`.
3. `ProfileActions` embeds `FriendActions` on another student's profile.
4. `FriendActions` shows an enabled Add friend button for state `none`. Sent, received, friends and blocked states have other controls.

No new schema is necessary for this display requirement. Sending a request belongs to SRS-114.2 and is not performed for this acceptance check.
