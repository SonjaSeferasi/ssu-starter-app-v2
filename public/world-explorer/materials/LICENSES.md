# Country terrain surface sets

The country levels use one regional rock or masonry set each. All sets are from
**Poly Haven** under **CC0 1.0 Universal**, retrieved on 2026-10-29 through the
public API (`https://api.polyhaven.com/files/<asset>`). The 1K diffuse and
OpenGL normal JPGs were checked against the provider MD5 values on download,
then reduced to 512 × 512 pixels (JPEG quality 0.86) so that each set is about
150 KB. Only the selected country's set is requested while playing. They are
surface maps on modelled 3D terrain, never backgrounds; vertex colours keep the
regional moss, snow, sand and grass bands. Procedural textures remain the
fallback when a file cannot load.
