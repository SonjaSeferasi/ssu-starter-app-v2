# Local country flags

193 SVG illustrations from [flag-icons](https://github.com/lipis/flag-icons), pinned to release **v7.3.2**, copyright Panayiotis Lipiridis and contributors, distributed under MIT. The complete notice is retained in `LICENSE.txt`. No npm package or flag CDN is loaded at runtime.

Only the catalog's 193 ISO alpha-2 country codes are imported. Each source URL and SHA-256 is recorded in `manifest.json`. The import rejects scripts, external links, images, embedded objects, document types and event handlers. Rebuild using `node scripts/world-explorer/import-flags.cjs`.

Most flags use the library's standardized 4:3 thumbnail presentation. Switzerland uses the square national flag. Nepal's twin-pennant outline remains transparent. These are reference illustrations, not legal manufacturing specifications. Antarctica is not a country and is shown with a neutral snowflake expedition symbol rather than a national flag.

## Recent and contested flag cases

- Syria: the asset has green, white and black bands with three red stars. The [UN reported the new three-star flag raising for April 25, 2025](https://www.un.org/sg/en/content/highlight/2025-04-24.html); the [UN ceremony recording](https://webtv.un.org/en/asset/k1w/k1wk7g2zfp) confirms the change.
- Kyrgyzstan: the asset uses the straight-ray sun design, matching the [presidential state-symbols page's December 2023 amendment](https://www.president.kg/ru/about/symbol).
- Afghanistan: this atlas deliberately retains the black-red-green diplomatic tricolor in the pinned set, consistent with the [Afghan diplomatic mission's flag description](https://www.afghanembassy.ca/about-afghanistan/afghanistan-flag.html). Afghanistan's de facto authorities use a different flag; this is not presented as a universally uncontested symbol or a claim about government recognition. The flag component provides that context in its image title.
